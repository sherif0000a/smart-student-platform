## 🚀 دَلِيلُ الرَّفْعِ عَلَى GITHUB وَ VERCEL (خُطْوَةً بِخُطْوَةٍ):

### أَوَّلاً: خُطُوَاتُ الرَّفْعِ عَلَى GITHUB 🐙

1. **تأكد من تثبيت Git على جهازك.**
2. **افتح مجلد المشروع في الـ Terminal / Command Prompt:**
```bash
# 1. تهيئة مستودع Git محلي
git init

# 2. إضافة كافة الملفات المجهزة
git add .

# 3. حفظ التغييرات مع رسالة واضحة
git commit -m "الإصدار الأول الكامل: منصة الطالب المجتهد - الصف الثالث الابتدائي"

# 4. تغيير اسم الفرع الرئيسي إلى main
git branch -M main

# 5. أنشئ مستودعاً جديداً فارغاً على موقع github.com باسم: al-talib-al-mujtahid
# ثم اربطه بالجهاز (استبدل YOUR_USERNAME باسم حسابك على جيت هاب):
git remote add origin https://github.com/YOUR_USERNAME/al-talib-al-mujtahid.git

# 6. ارفع الملفات إلى GitHub:
git push -u origin main
```

### ثَانِياً: خُطُوَاتُ النَّشْرِ عَلَى VERCEL (نَقْرَةٌ وَاحِدَةٌ مجانية ⚡)

1. ادخل إلى موقع [Vercel](https://vercel.com) وسجّل الدخول بحساب GitHub الخاص بك.
2. اضغط على زر **"Add New..."** ثم اختر **"Project"**.
3. ستجد مستودع `al-talib-al-mujtahid` في القائمة؛ اضغط أمامه على **"Import"**.
4. **إعدادات المشروع (تلقائية بالكامل بفضل وجود vercel.json):**
   - **Framework Preset**: `Vite`
   - **Build Command**: `vite build`
   - **Output Directory**: `dist`
5. *(اختياري لتفعيل الذكاء الاصطناعي السحابي الحي)*: في قسم **Environment Variables**، أضف المتغير التالي:
   - `GEMINI_API_KEY`: مفتاحك من Google AI Studio (ملاحظة: التطبيق يعمل فوراً بدون إنترنت أو مفاتيح بفضل قاعدة البيانات المحلية المدمجة).
6. اضغط على **"Deploy"**.
7. خلال أقل من دقيقة، سيكون موقعك منشوراً ويعمل على رابط عالمي سريع مثل:  
   `https://al-talib-al-mujtahid.vercel.app`
